# 从大厂出来，远程工作 4 年后，发现自己似乎本质不适合远程（古法手搓贴，已焦虑

先放个简历 [zh](https://blog.ashesborn.cloud/blog/Chinese-anymouns) | [en](https://blog.ashesborn.cloud/blog/frontend-agent-engineer-resume) 在这

## background

2022 年初，在工作稳定，部门氛围友好，只是项目停滞的情况，wlb/不用通勤的诱惑下，毅然选择了裸辞寻找远程机会。

在紧张刺激的三个月找工作+upwork 闯荡后，寻找到了第一份真·外企+远程的工作，工作内容是将 salesforce 中的流程，从 0 到 1 迁移到自研的规则引擎中，作为上一份工作内容是开发低代码引擎的我来说这工作内容匹配度可以说是相当高了。

就这样，我带着对新生活的向往和相对自由的时间开始了伪·数字游民的生活。

## 开端

为什么说我是`伪·数字游民`呢，最重要的论据就是我一点也‘游’不起来，4 年总共度假 3 次，旅居更是一次没有，我总是说服自己“家里的三块屏幕不比带个电脑低头开发好吗？”。所以这 4 年的大部分时间我都是待在老家的。

但从目前的自我剖析看来，我还是一个非常需要社交和职业交流的人，所以我开始尝试大量的线下社交活动，捡起来曾经没时间学习和深入的网球/音乐，深度泡清吧/咖啡馆，并且迅速构建起了新的朋友圈。这段时间，白天（ 9-17 ）我可以继续干着自己喜欢的工作内容，晚上可以和新朋友吹吹以往工作的场景，见过某些大人物，支持过哪些重要场景，一切看起来都在向我设想的方向前进。可惜，好景不长。

## 转变

第二年，美联储加息节奏依旧，新公司是一家 USA 上市的地产中介，这就导致 USA 地产的交易市场萎靡，同事们都担心自己被裁，然后出现了频繁的组织架构调整。这时候，我的 Leader 就是一个 TX 10+经历的`EM`了。

从他身上，我仿佛又看到了第一家公司隔壁组那种，只管汇报/上传下达/多年不编码/满嘴互联网精神的 leader 。他作为一个前端出身，似乎是没做过后端开发的 EM ，经常也会给后端的 engineer 提一些架构/代码设计问题，并且不知道从什么时候开始，我的 review and approve PR 的权限也被收回了，从此我的代码就要交给他和另一人开始审核了。

叠加 USA 公司新的人事变动，PR 的合并成了审核我们 remoter 工作量的标准，于是我的公司生涯时间似乎也开始了倒计时。

## 爆点

我的 PR 合并开始频频被卡，即使我是从 0 开发了规则引擎的人，我对它的改动从代码质量到影响范围，从 PR 描述规范到编码习惯，甚至频繁使用 useMemo 在别人看来也是错误的，函数式编程的理念，也被别人一个个快速合并的 `let, useRef`快速打破。有的时候，一个星期都合不了一个 PR ，无法将一个 jira 的 ticket 标记成 ready for qa。

我尝试过在“扁平化”管理的会议上聊过，也争论过，但是没什么用，直到我看到另一个人如下的代码也能被合并时，我释怀了

```typescript
const ComponentA = () => {
  const ComponentB = () => <div></div>
  return <ComponentB />
}
```

我基本认定我就是那个要被干掉的人。

## 尝试

虽然想不通为什么被针对，但是本着认真负责的职业操守，我还是尝试去融入这种让我恶心的代码中。不过，我已经无法像之前那样全情投入到工作了，我开始尝试发展一些副业。

我开始将上班之外的工作，侵入到社交场合，每次社交我似乎都在寻找队友，发掘需求。

现在回想起来，自己的想法还是有点过于理想了。我居然在一个四线城市，妄图寻找能一起沉浸式投入到互联网式的软件开发，在一个所有采购都在靠围标串标或得订单的市场发掘需求。

## 失业和再就业和再失业

2025 年 9 月，不出意外的我被干掉了，不过我还是在最后和+2 以及 HR 的会议失去了一些体面，因为这个 EM 居然以我技术不行/产出不够作为理由。但是也没爆太狠，10 分钟就控制住自己的情绪了。事情既然已经发生，并且也有预期，我没必要再和他们争论了。不过我离职的最后一秒，还在 oncall 给别人解决问题，只到发现自己的权限突然消失，也是有点可笑了。

这次失业后，我没去找工作，而是想着沉淀一下，认真干干之前寻找到的一些可行的方向，但这时候，一个 Web3 的机会找到了我，是从 0 开始开发交易平台，我本着“先干着吧，虽然是简单的业务，但是至少有钱赚，并且能感受下新行业”加入了新的团队。

前 3 个月也像是上家一样丝滑，再加上 AI 的快速进步，我感觉自己的生产力得到了质的飞跃，但好景不长，EU 的团队又收走了我 Merge PR 的权限。剧本和上面类似，但更可笑的是，他们声称自己的编码规范是需要被遵守的，但是自己的 PR 往往也不遵守，说是 UI 要像素级还原，但即使结合 Figma MCP 他们也没有做到。今年 7 月中，由于 EU 的一些政策变动，导致需求萎缩，最后这个团队我也没待住。

## 复盘

说是复盘，我也不知道怎么复盘，我的选择似乎都对，但也似乎都错。技术上，我能完成这些业务，包括我现在自己开发的 https://github.com/sadofriod/graphrag-ts 似乎也能证明并不差。和人的相处，我也能寻找到朋友，从同事中维护比较好的关系。但我还是失业了，看起来我似乎无法完全融入远程的工作方式，我还是希望能面对面的和人交流讨论技术和业务，我享受那种大家为了一个目标，用自己的专业能力达成目标的过程。似乎是远程切断了这些。曾经即使是下班之后，我也愿意钻研技术，微前端/元编程/react 源码，但远程之后，我时刻都在家，技术的钻研虽然没落下，但是这个事给我的反馈也没那么大了。

## 未来的展望

目前已经失业三个月了，我开始有一些不好情绪，虽然是上周 4 才开始找工作的，但是情绪的起伏和焦躁已经极度明显了。这三个月中，我试着继续沉淀自己的项目/产品/技术，寻找着变现途径，但是正反馈在起步阶段确实太少了，结合我的心态和四年没有线下的和人面对面的交流技术，最近真的有点抑郁倾向（昨天和咖啡馆老板聊天，突然莫名想哭）。

但是我知道，这些都是正常的情况，只是需要稳定心态继续去做，无论是找工作还是其他的事情。

## 总结

前两年看到“人总是美化自己没走过的路”，我觉得没错，但是我想稍做补充“但总归得走走看”。可能有些词不达意，但这差不多是我这 4 年的非技术性结论之一了。
